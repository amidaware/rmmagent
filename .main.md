This is the main entry point for the Tactical RMM agent, providing a comprehensive command-line interface for agent installation, service management, and various operational tasks with support for OpenFrame integration.

## Key Components

- **Command-line flags**: Extensive set of flags for installation parameters, logging configuration, API settings, and OpenFrame mode
- **Mode-based execution**: Switch statement handling different operational modes (install, service, tasks, checks, etc.)
- **Logging setup**: Configurable logging with file or stdout output and multiple log levels
- **Cross-platform support**: Platform-specific behavior for Windows and Unix-like systems
- **Service integration**: Integration with system service management via kardianos/service package

## Usage Example

```go
// Basic version check
./rmmagent -version

// Install agent with required parameters
./rmmagent -m install \
    -api "https://api.example.com" \
    -client-id 1 \
    -site-id 2 \
    -auth "token123" \
    -desc "Production Server"

// Run in service mode
./rmmagent -m svc

// Run specific task with custom logging
./rmmagent -m taskrunner -p 123 -log DEBUG -logto stdout

// OpenFrame mode installation
./rmmagent -m install \
    -openframe-mode \
    -openframe-secret "secret123" \
    -openframe-token-path "/path/to/token"
```

The application supports over 20 different operational modes including installation, service management, health checks, software inventory, and system maintenance tasks.
