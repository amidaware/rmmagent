A connection manager that handles HTTP REST and NATS messaging connections for the Openframe agent, providing token-based authentication updates and connection management.

## Key Components

- **OpenframeConnectionManager**: Main struct that manages both REST and NATS connections
- **NewOpenframeConnectionManager()**: Constructor that initializes the manager with a REST client and logger
- **SetNatsConnection()**: Sets the NATS connection reference after initialization
- **UpdateRestClient()**: Updates the REST client's authorization header with a new bearer token
- **UpdateNatsConnection()**: Updates NATS connection with a new token and forces reconnection

## Usage Example

```go
// Create connection manager
logger := logrus.New()
restClient := resty.New()
connManager := NewOpenframeConnectionManager(restClient, logger)

// Set NATS connection when available
natsConn, _ := nats.Connect("nats://localhost:4222")
connManager.SetNatsConnection(natsConn)

// Update authentication tokens
newToken := "eyJhbGciOiJIUzI1NiIs..."
connManager.UpdateRestClient(newToken)
connManager.UpdateNatsConnection(newToken)
```

The manager uses a lazy initialization pattern for NATS connections, allowing the REST client to be configured first while NATS can be added later. Token updates trigger automatic reconnection for NATS while simply updating headers for REST requests.
