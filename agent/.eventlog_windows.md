Windows Event Log reader that provides access to Windows system event logs with filtering capabilities.

## Key Components

- **`GetEventLog(logName, searchLastDays)`** - Main function that reads Windows event log entries with optional time-based filtering
- **`getEventType(et)`** - Converts Windows event type constants to human-readable strings
- **`bytesToString(b)`** - Utility function to convert Windows UTF-16 byte arrays to Go strings
- **`getResourceMessage(providerName, sourceName, eventID, argsptr)`** - Resolves event messages from Windows registry and message files

## Usage Example

```go
// Create agent instance
agent := &Agent{Logger: logger}

// Get all event log entries from the last 7 days
events := agent.GetEventLog("Application", 7)

// Get system events from the last 24 hours  
systemEvents := agent.GetEventLog("System", 1)

// Get all available events (no time filter)
allEvents := agent.GetEventLog("Security", 0)

// Process the returned events
for _, event := range events {
    fmt.Printf("Event ID: %d, Type: %s, Source: %s\n", 
               event.EventID, event.EventType, event.Source)
    fmt.Printf("Time: %s\n", event.Time)
    fmt.Printf("Message: %s\n", event.Message)
}
```

The function returns a slice of `rmm.EventLogMsg` structs containing event details including source, type, ID, message, timestamp, and unique identifier. It uses Windows API calls to read event log records backwards from newest to oldest, with proper memory management and error handling for Windows-specific operations.
