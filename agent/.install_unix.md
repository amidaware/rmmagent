Unix-specific installer implementation for the Tactical RMM agent, handling configuration creation and cleanup operations on non-Windows systems.

## Key Components

- **`installerMsg()`** - Handles installer log messages and fatal errors during installation
- **`createAgentConfig()`** - Creates the agent configuration file using Viper with connection parameters and OpenFrame mode support
- **`checkExistingAndRemove()`** - Removes existing agent installations, specifically handling macOS mesh agents and plist files
- **`DisableSleepHibernate()`** - No-op stub for Unix systems (Windows-only feature)
- **`EnablePing()`** - No-op stub for Unix systems (Windows-only feature)  
- **`EnableRDP()`** - No-op stub for Unix systems (Windows-only feature)

## Usage Example

```go
// Create agent configuration during installation
createAgentConfig(
    "https://rmm.example.com",     // baseurl
    "agent-123",                   // agentid
    "https://api.rmm.example.com", // apiurl
    "auth-token",                  // token
    "agent-pk",                    // agentpk
    "/path/to/cert",               // cert
    "",                            // proxy
    "/opt/mesh",                   // meshdir
    "4222",                        // natsport
    false,                         // insecure
    true,                          // openframeMode
)

// Check and remove existing installations
agent := &Agent{}
agent.checkExistingAndRemove(false) // silent=false

// Log installer messages
agent.installerMsg("Installation complete", "info", false)
```

The build constraint `//go:build !windows` ensures this file is only compiled for Unix-like systems, with Windows-specific functionality implemented as no-op stubs.
