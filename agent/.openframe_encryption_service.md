A service that provides AES-GCM decryption capabilities for the OpenFrame agent system. The service handles base64-encoded encrypted data and returns the decrypted plaintext.

## Key Components

- **OpenframeEncryptionService**: Main service struct that holds the encryption key
- **NewOpenframeEncryptionService()**: Constructor function that creates a new encryption service instance
- **Decrypt()**: Method that decrypts base64-encoded data using AES-GCM cipher with embedded nonce

## Usage Example

```go
// Create a new encryption service with a 32-byte key
encryptionKey := "your-32-byte-encryption-key-here"
encService := NewOpenframeEncryptionService(encryptionKey)

// Decrypt base64-encoded data
encryptedData := "base64-encoded-encrypted-data"
decryptedBytes, err := encService.Decrypt(encryptedData)
if err != nil {
    log.Printf("Decryption failed: %v", err)
    return
}

// Use the decrypted data
plaintext := string(decryptedBytes)
fmt.Printf("Decrypted message: %s", plaintext)
```

The service uses AES-GCM (Galois/Counter Mode) for authenticated encryption, extracting the nonce from the first bytes of the encrypted data. Error handling is included for base64 decoding, cipher creation, and decryption operations.
