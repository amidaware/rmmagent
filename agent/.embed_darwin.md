Platform-specific Go file for macOS (Darwin) that embeds a shell script to fix MeshCentral installation issues on macOS Ventura and provides functionality to execute it.

## Key Components

- **Build Constraints**: Uses `//go:build darwin` to compile only on macOS systems
- **Embedded Script**: `ventura_mesh_fix` - Contains the contents of `macos_fix_mesh_install.sh` script embedded at compile time
- **FixVenturaMesh()**: Method on the Agent struct that executes the embedded mesh fix script

## Usage Example

```go
// Create an agent instance
agent := &Agent{}

// Execute the Ventura mesh fix script
// This will run the embedded macos_fix_mesh_install.sh script
// with a 45-second timeout
agent.FixVenturaMesh()
```

The embedded script is executed using the agent's `RunScript` method with the following parameters:
- Script content: `ventura_mesh_fix` (embedded shell script)
- Script name: "foo" 
- Arguments: empty slice
- Timeout: 45 seconds
- No elevated privileges required
- No environment variables
- Not detached execution
- No working directory specified

This approach allows the agent to carry platform-specific fix scripts as embedded resources, eliminating the need for external script files on macOS systems.
