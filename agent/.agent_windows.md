This file provides Windows-specific implementations for the Tactical RMM agent, handling configuration management, script execution, and system utilities specific to Windows environments.

## Key Components

**Configuration Management:**
- `NewAgentConfig()` - Reads agent configuration from Windows registry (`SOFTWARE\TacticalRMM`)
- Retrieves connection settings, API URLs, certificates, proxy settings, and OpenFrame mode parameters

**Script Execution:**
- `RunScript()` - Executes scripts in multiple shells (PowerShell, Python, CMD, Nushell, Deno)
- Supports running as different users with token impersonation
- Handles environment variables and custom permissions for Deno scripts
- Creates temporary files with appropriate extensions and cleanup

**Command Execution:**
- `CMD()` - Simple command execution with timeout and detached process support
- `CMDShell()` - Shell-specific command execution with support for CMD and PowerShell
- `SetDetached()` - Creates process attributes for detached execution

**System Information:**
- `GetDisks()` - Retrieves information about fixed disk drives using Windows API
- Filters for fixed drives only (type 3) and provides usage statistics

## Usage Example

```go
// Create agent configuration from registry
config := NewAgentConfig()
fmt.Printf("Agent ID: %s, Base URL: %s\n", config.AgentID, config.BaseURL)

// Execute a PowerShell script
agent := &Agent{WinTmpDir: "C:\\temp"}
stdout, stderr, exitcode, err := agent.RunScript(
    "Get-Process | Select-Object Name",
    "powershell",
    []string{},
    30, // timeout in seconds
    false, // don't run as user
    []string{}, // no env vars
    false, // nushell config
    "", // deno permissions
)

// Execute a simple command
output, err := CMD("ipconfig", []string{"/all"}, 10, false)
fmt.Printf("Output: %s\n", output[0])

// Get disk information
disks := agent.GetDisks()
for _, disk := range disks {
    fmt.Printf("Drive %s: %s used of %s total\n", 
        disk.Device, disk.Used, disk.Total)
}
```
