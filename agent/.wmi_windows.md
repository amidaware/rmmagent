A Windows-specific WMI (Windows Management Instrumentation) interface module that provides hardware and system information gathering capabilities for the Tactical RMM agent.

## Key Components

### Hardware Information Functions
- **`GetWin32_USBController()`** - Retrieves USB controller information
- **`GetWin32_Processor()`** - Gets processor details with fallback support for extended properties
- **`GetWin32_DesktopMonitor()`** - Collects desktop monitor information
- **`GetWin32_NetworkAdapter()`** - Retrieves network adapter details
- **`GetWin32_DiskDrive()`** - Gets disk drive information
- **`GetWin32_VideoController()`** - Collects video controller data

### System Information Functions
- **`GetWin32_ComputerSystemProduct()`** - Retrieves computer system product information
- **`GetWin32_BIOS()`** - Gets BIOS information with extended property fallback
- **`GetWin32_ComputerSystem()`** - Collects computer system details
- **`GetWin32_NetworkAdapterConfiguration()`** - Retrieves network configuration
- **`GetWin32_PhysicalMemory()`** - Gets physical memory information
- **`GetWin32_OperatingSystem()`** - Collects OS information
- **`GetWin32_BaseBoard()`** - Retrieves motherboard details

### Main Interface
- **`GetWMIInfo()`** - Aggregates all WMI information into a single map

## Usage Example

```go
// Get comprehensive WMI information
agent := &Agent{Logger: logger}
wmiInfo := agent.GetWMIInfo()

// Access specific hardware info
processors, err := GetWin32_Processor()
if err != nil {
    log.Printf("Error getting processor info: %v", err)
}

// Get disk information
disks, err := GetWin32_DiskDrive()
if err != nil {
    log.Printf("Error getting disk info: %v", err)
}
```

All functions return data in a format compatible with the Python agent for backwards compatibility, wrapping each result in an additional array structure. Functions with "EX" variants attempt to use extended WMI classes first, falling back to standard classes if needed.
