This file implements the main RPC server functionality for a Tactical RMM agent, handling NATS message subscriptions and executing various system management commands remotely.

## Key Components

**Core Structure:**
- `NatsMsg` - Message payload structure containing function calls, parameters, and metadata
- `RunRPC()` - Main RPC server that connects to NATS and processes incoming messages
- Message handlers for system operations (processes, services, scripts, updates, etc.)

**Key Functions:**
- NATS connection setup and subscription management
- Command execution handlers (`rawcmd`, `runscript`, `runscriptfull`)
- System management (`winservices`, `winsvcaction`, `procs`, `killproc`)
- Scheduled task management (`schedtask`, `delschedtask`, `listschedtasks`)
- System operations (`shutdown`, `rebootnow`, `needsreboot`, `sysinfo`)
- Software management (`softwarelist`, `patchmgmt`)

**Concurrency Controls:**
- Atomic lockers for agent updates and Windows update operations
- Goroutine-based message handling for concurrent operations

## Usage Example

```go
// Initialize and start the RPC server
agent := &Agent{
    AgentID: "agent-123",
    NatsServer: "nats://localhost:4222",
    Logger: logger,
}

// Start the RPC server (blocking call)
agent.RunRPC()

// The server will handle incoming NATS messages like:
// - ping/pong health checks
// - Script execution requests
// - System information queries
// - Service management operations
// - Scheduled task management
```

The RPC server uses MessagePack encoding for efficient binary communication and responds to various function calls defined in the `NatsMsg.Func` field, making it the central communication hub for remote agent management.
