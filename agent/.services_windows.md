Provides comprehensive Windows service management capabilities for the Tactical RMM agent, enabling control, monitoring, and configuration of system services through the Windows Service Control Manager API.

## Key Components

**Core Functions:**
- `GetServiceStatus()` - Retrieves current status of a specific service
- `ControlService()` - Starts or stops services with timeout handling
- `EditService()` - Modifies service startup configuration (auto, manual, disabled)
- `GetServiceDetail()` - Returns detailed service information including PID, binary path, and configuration
- `GetServices()` - Lists all system services with their properties
- `WaitForService()` - Polls service status until desired state is reached

**Helper Functions:**
- `serviceExists()` - Checks if a service is installed
- `serviceStatusText()` - Converts Windows status codes to readable strings
- `serviceStartType()` - Converts startup type codes to descriptive text

## Usage Example

```go
// Get status of a specific service
status, err := GetServiceStatus("spooler")
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Service status: %s\n", status)

// Control a service (stop with timeout)
agent := &Agent{}
result := agent.ControlService("spooler", "stop")
if !result.Success {
    log.Printf("Failed to stop service: %s", result.ErrorMsg)
}

// Modify service startup type
result = agent.EditService("spooler", "manual")
if result.Success {
    fmt.Println("Service startup type changed to manual")
}

// Get detailed service information
detail := agent.GetServiceDetail("spooler")
fmt.Printf("Service: %s, PID: %d, Status: %s\n", 
    detail.DisplayName, detail.PID, detail.Status)

// List all services
services := agent.GetServices()
for _, svc := range services {
    fmt.Printf("%s: %s\n", svc.Name, svc.Status)
}
```
