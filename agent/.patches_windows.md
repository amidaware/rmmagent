This file implements Windows update management functionality for the Tactical RMM agent, providing methods to retrieve available updates and install specific updates on Windows systems.

## Key Components

- **`GetWinUpdates()`** - Retrieves all available Windows updates (both installed and uninstalled) and sends them to the RMM server
- **`InstallUpdates(guids []string)`** - Installs Windows updates specified by their GUIDs and reports installation status
- **WUA Integration** - Uses Windows Update Agent (WUA) APIs through helper functions like `WUAUpdates()` and `NewUpdateSession()`
- **Reboot Detection** - Checks if system restart is required after update installation

## Usage Example

```go
// Get all available Windows updates and report to server
agent.GetWinUpdates()

// Install specific updates by GUID
updateGuids := []string{
    "12345678-1234-1234-1234-123456789012",
    "87654321-4321-4321-4321-210987654321",
}
agent.InstallUpdates(updateGuids)
```

The `GetWinUpdates()` method queries for software updates using WUA filters and logs detailed information including GUID, download status, installation status, and KB article IDs. The `InstallUpdates()` method iterates through provided update GUIDs, installs each update individually, handles superseded updates, and checks if a system reboot is required after installation. Both methods communicate results back to the Tactical RMM server via REST API calls.
