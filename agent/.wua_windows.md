Windows Update Agent (WUA) integration for managing Windows updates through COM interfaces. Provides functionality to search, download, and install Windows updates using Microsoft's Windows Update Agent API.

## Key Components

### Core Types
- `IUpdateSession` - Wrapper for Microsoft Update Session COM object with thread-safe mutex locking
- `IUpdateCollection` - Collection wrapper for managing groups of Windows updates
- `IUpdate` - Individual Windows update wrapper with metadata extraction methods

### Main Functions
- `NewUpdateSession()` - Creates a new WUA session with COM initialization
- `WUAUpdates(query)` - Queries for available updates using WUA search syntax
- `InstallWUAUpdate()` - Downloads and installs a single Windows update
- `DownloadWUAUpdateCollection()` - Downloads multiple updates in batch
- `InstallWUAUpdateCollection()` - Installs multiple updates in batch

### Helper Methods
- `kbaIDs()` - Extracts Knowledge Base article IDs from updates
- `categories()` - Retrieves update categories and category IDs
- `moreInfoURLs()` - Gets additional information URLs for updates
- `extractPkg()` - Converts COM update objects to `rmm.WUAPackage` structs

## Usage Example

```go
// Query for available security updates
packages, err := WUAUpdates("IsInstalled=0 and Type='Software' and CategoryIDs contains '0fa1201d-4330-4fa8-8ae9-b877473b6441'")
if err != nil {
    return fmt.Errorf("failed to query updates: %v", err)
}

// Install a specific update
session, err := NewUpdateSession()
if err != nil {
    return err
}
defer session.Close()

// Download and install update collection
err = session.InstallWUAUpdateCollection(updateCollection)
if err != nil {
    return fmt.Errorf("installation failed: %v", err)
}
```

The implementation uses thread-safe COM object management and handles Windows Update Agent EULA acceptance automatically during installation.
