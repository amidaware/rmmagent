Manages automatic refresh of Openframe access tokens on a scheduled interval to maintain authenticated connections.

## Key Components

- **OpenframeTokenRefresher** - Main struct that orchestrates token refresh operations
- **NewOpenframeTokenRefresher()** - Constructor function that initializes the refresher with required dependencies
- **Start()** - Begins the cron job that refreshes tokens every 5 seconds
- **Stop()** - Gracefully shuts down the token refresh scheduler
- **refreshToken()** - Core refresh logic that extracts new tokens and updates connections

## Usage Example

```go
// Initialize the token refresher
refresher := NewOpenframeTokenRefresher(
    agent,
    connectionManager,
    tokenExtractor,
    logger,
)

// Start automatic token refresh (every 5 seconds)
err := refresher.Start()
if err != nil {
    log.Fatalf("Failed to start token refresher: %v", err)
}

// Gracefully stop when shutting down
defer refresher.Stop()
```

The refresher automatically:
- Extracts fresh tokens using the token extractor
- Compares with existing tokens to avoid unnecessary updates
- Updates both REST client and NATS connection credentials
- Logs all operations for debugging and monitoring
