This file provides Windows-specific installation functionality for the Tactical RMM agent, handling registry configuration, existing installation detection, and user interface interactions during the installation process.

## Key Components

- `createAgentConfig()` - Creates Windows registry entries for agent configuration including base URL, agent ID, API credentials, proxy settings, and OpenFrame mode support
- `checkExistingAndRemove()` - Detects existing Tactical RMM installations and prompts for removal before proceeding with new installation
- `installerMsg()` - Displays installation messages via Windows message boxes (GUI mode) or console output (silent mode)

## Usage Example

```go
// Create agent configuration in Windows registry
createAgentConfig(
    "https://rmm.example.com",     // base URL
    "agent-123",                   // agent ID
    "https://api.rmm.example.com", // API URL
    "auth-token",                  // authentication token
    "agent-pk-key",                // agent primary key
    "ssl-cert",                    // SSL certificate
    "proxy:8080",                  // proxy settings
    "C:\\mesh",                    // mesh directory
    "4222",                        // NATS port
    false,                         // insecure mode
    true,                          // OpenFrame mode
)

// Check for existing installation before proceeding
agent := &Agent{ProgramDir: "C:\\Program Files\\TacticalAgent"}
agent.checkExistingAndRemove(false) // interactive mode

// Display installation message
agent.installerMsg("Installation completed successfully", "info", false)
```

The registry configuration is stored under `HKEY_LOCAL_MACHINE\SOFTWARE\TacticalRMM` and supports both standard Tactical RMM parameters and OpenFrame-specific settings.
