This file implements the main service loop for the Tactical RMM agent, managing periodic check-ins with the server and coordinating various monitoring tasks.

## Key Components

- **`RunAsService(nc *nats.Conn)`** - Entry point that starts the agent service and check runner in separate goroutines
- **`AgentCheckInConfig`** - Configuration struct defining check-in intervals and feature flags for the agent
- **`AgentSvc(nc *nats.Conn)`** - Main service loop that handles initialization, periodic tasks, and timed check-ins via NATS messaging
- **`AgentStartup()`** - Sends initial startup notification to the server API
- **`GetCheckInConfFromAPI()`** - Fetches agent configuration from the server with fallback to random intervals

## Usage Example

```go
// Initialize NATS connection
nc, err := nats.Connect("nats://server:4222")
if err != nil {
    log.Fatal(err)
}

// Create agent instance
agent := &Agent{
    AgentID: "agent-123",
    Logger:  logger,
    rClient: httpClient,
}

// Start the agent service
agent.RunAsService(nc)
```

The service runs continuous tickers for different monitoring tasks (hello messages, agent info, Windows services, disk usage, etc.) with configurable intervals. It handles platform-specific operations like Python installation on Windows and mesh synchronization, while providing graceful fallbacks when server communication fails.
