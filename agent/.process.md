This Go file provides process management functionality for the Tactical RMM agent, enabling process enumeration and cleanup of hung update processes.

## Key Components

- **`GetProcsRPC()`** - Retrieves comprehensive system process information including PID, memory usage, CPU percentage, and username for RPC communication
- **`KillHungUpdates()`** - Identifies and terminates hung agent update processes to prevent system conflicts

## Usage Example

```go
// Initialize agent instance
agent := &Agent{
    Logger: logger,
}

// Get all system processes for monitoring
processes := agent.GetProcsRPC()
for _, proc := range processes {
    fmt.Printf("Process: %s (PID: %d, CPU: %s%%, Mem: %d bytes, User: %s)\n",
        proc.Name, proc.Pid, proc.CPU, proc.MemBytes, proc.Username)
}

// Clean up any hung update processes
agent.KillHungUpdates()
```

The implementation uses both `go-sysinfo` and `gopsutil` libraries to gather comprehensive process metrics. The `GetProcsRPC()` method returns a slice of `ProcessMsg` structs containing process details suitable for RPC transmission, while `KillHungUpdates()` specifically targets deprecated `winagent-v*` and current `tacticalagent-v*` executables that may be stuck during updates.
