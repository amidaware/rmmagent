A token extraction utility that securely retrieves and decrypts OpenFrame authentication tokens from encrypted files on disk.

## Key Components

- **OpenframeTokenExtractor** - Main struct that handles secure token retrieval operations
- **NewOpenframeTokenExtractor()** - Constructor function that initializes the extractor with encryption service and file path
- **ExtractToken()** - Core method that reads encrypted token data from file and returns the decrypted token string

## Usage Example

```go
// Initialize encryption service
encryptionService := NewOpenframeEncryptionService("your-key")

// Create token extractor
tokenExtractor := NewOpenframeTokenExtractor(encryptionService, "/path/to/encrypted/token.dat")

// Extract and decrypt token
token, err := tokenExtractor.ExtractToken()
if err != nil {
    log.Fatal("Failed to extract token:", err)
}

// Use the decrypted token for authentication
fmt.Printf("Retrieved token: %s", token)
```

The extractor provides secure token management by leveraging the OpenframeEncryptionService for decryption operations, ensuring sensitive authentication data remains protected when stored on disk.
