This file provides Windows-specific functionality for managing Chocolatey package manager installations through the Tactical RMM agent. It handles both installing Chocolatey itself and using it to install packages.

## Key Components

- **`InstallChoco()`** - Downloads and installs Chocolatey package manager using PowerShell
- **`InstallWithChoco(name string)`** - Installs a specified package using Chocolatey with forced installation options

## Usage Example

```go
// Install Chocolatey package manager
agent := &Agent{AgentID: "agent123"}
agent.InstallChoco()

// Install a package using Chocolatey
output, err := agent.InstallWithChoco("git")
if err != nil {
    log.Printf("Failed to install package: %v", err)
} else {
    log.Printf("Installation output: %s", output)
}
```

The `InstallChoco()` method downloads the official Chocolatey installation script from `chocolatey.org/install.ps1` and executes it via PowerShell, reporting the installation status back to the RMM server. The `InstallWithChoco()` method locates the Chocolatey executable and runs package installations with forced options to ensure reliable deployment. Both methods include proper error handling and logging for troubleshooting installation issues.
