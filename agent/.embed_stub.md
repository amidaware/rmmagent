This file provides a stub implementation for non-macOS platforms where Ventura mesh fixing functionality is not required. It uses Go's build constraints to ensure this version is compiled only on systems other than Darwin (macOS).

## Key Components

- **Build constraints**: `//go:build !darwin` and `// +build !darwin` ensure compilation only on non-macOS systems
- **FixVenturaMesh()**: Empty stub method that satisfies the Agent interface without performing any operations

## Usage Example

This file is automatically selected during compilation based on the target platform:

```go
// On non-macOS systems, this stub will be used
agent := &Agent{}
agent.FixVenturaMesh() // No-op on Linux, Windows, etc.
```

The stub pattern allows the same codebase to work across platforms while providing macOS-specific functionality only where needed. When building for Linux or Windows, this empty implementation ensures the `FixVenturaMesh` method exists without the macOS-specific logic that would be present in a corresponding `embed_darwin.go` file.
