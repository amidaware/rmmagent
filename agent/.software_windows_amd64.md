This Windows-specific implementation retrieves installed software information from Windows systems using the Windows API.

## Key Components

- **GetInstalledSoftware()**: Agent method that returns a slice of `trmm.WinSoftwareList` containing details about all installed software on the Windows system
- **wapi.InstalledSoftwareList()**: External API call to retrieve raw software data from Windows registry
- **CleanString()**: Utility function to sanitize string data from Windows API responses
- **ByteCountSI()**: Helper function to convert size values to human-readable format

## Usage Example

```go
// Initialize agent and get installed software
agent := &Agent{}
softwareList := agent.GetInstalledSoftware()

// Iterate through installed software
for _, software := range softwareList {
    fmt.Printf("Software: %s\n", software.Name)
    fmt.Printf("Version: %s\n", software.Version)
    fmt.Printf("Publisher: %s\n", software.Publisher)
    fmt.Printf("Install Date: %s\n", software.InstallDate)
    fmt.Printf("Size: %s\n", software.Size)
    fmt.Printf("Location: %s\n", software.Location)
    fmt.Printf("---\n")
}
```

The method queries the Windows registry for installed programs, formats the installation date as `YYYY-MM-DD`, converts estimated sizes from KB to human-readable format, and sanitizes all string fields to ensure clean data output. Returns an empty slice if the Windows API call fails.
