This file implements the check execution system for a Tactical RMM agent, handling periodic monitoring tasks like disk usage, CPU load, memory usage, and service status checks.

## Key Components

### Core Functions
- **`CheckRunner()`** - Main goroutine that continuously executes checks at configured intervals
- **`GetCheckInterval()`** - Retrieves check execution interval from the RMM server
- **`RunChecks(force bool)`** - Orchestrates parallel execution of all check types using goroutines

### Check Types
- **`DiskCheck()`** - Monitors disk space usage and availability
- **`CPULoadCheck()`** - Measures average CPU load percentage
- **`MemCheck()`** - Calculates memory usage percentage
- **`ScriptCheck()`** - Executes custom scripts (PowerShell, Python, batch)
- **`EventLogCheck()`** - Searches Windows event logs for specific events
- **`PingCheck()`** - Tests network connectivity to specified hosts
- **`WinSvcCheck()`** - Monitors Windows service status

### Result Structures
- **`ScriptCheckResult`** - Contains script execution output and runtime metrics
- **`DiskCheckResult`** - Disk usage statistics and existence status
- **`CPUMemResult`** - CPU/memory percentage data
- **`EventLogCheckResult`** - Filtered event log entries
- **`WinSvcCheckResult`** - Service status and management actions

## Usage Example

```go
// Start the check runner (typically called as a goroutine)
go agent.CheckRunner()

// Manually force all checks to run immediately
err := agent.RunChecks(true)
if err != nil {
    log.Printf("Failed to run checks: %v", err)
}

// Execute a specific disk check
diskCheck := rmm.Check{
    CheckType: "diskspace",
    Disk: "/",
    CheckPK: 123,
}
result := agent.DiskCheck(diskCheck)
```

The system uses concurrent goroutines with `sync.WaitGroup` to execute multiple checks simultaneously, then sends results back to the Tactical RMM server via HTTP PATCH requests.
