This file handles agent check-in functionality for the Tactical RMM system, managing periodic communication between agents and the NATS messaging server to report system status and information.

## Key Components

- **`NatsMessage()`** - Constructs and sends different types of status messages to the NATS server based on the specified mode
- **`DoNatsCheckIn()`** - Orchestrates the complete check-in process by establishing a NATS connection and sending all required message types
- **Message Types** - Supports multiple check-in modes including agent hello, Windows services, agent info, WMI data, disk information, and public IP reporting

## Usage Example

```go
// Perform a complete check-in cycle
agent := &Agent{
    AgentID: "agent-123",
    Version: "2.0.1",
    // ... other agent configuration
}

// Execute full check-in process
agent.DoNatsCheckIn()

// Or send individual message types
nc, err := nats.Connect(agent.NatsServer, opts...)
if err != nil {
    return
}
defer nc.Close()

// Send specific status updates
agent.NatsMessage(nc, "agent-hello")
agent.NatsMessage(nc, "agent-agentinfo") 
agent.NatsMessage(nc, "agent-disks")
```

The check-in process uses MessagePack encoding for efficient data serialization and includes random delays between messages to prevent server overload during mass agent deployments.
