This file provides Windows Task Scheduler integration for the Tactical RMM agent, enabling creation and management of scheduled tasks on Windows systems.

## Key Components

### Types
- **`SchedTask`** - Comprehensive struct defining scheduled task configuration including triggers, timing, execution details, and Windows-specific settings

### Methods
- **`CreateSchedTask(st SchedTask)`** - Creates a new Windows scheduled task with specified configuration, supporting multiple trigger types (daily, weekly, monthly, etc.)
- **`DeleteSchedTask(name string)`** - Removes a specific scheduled task by name
- **`CleanupSchedTasks()`** - Removes all TacticalRMM-related scheduled tasks during uninstall
- **`ListSchedTasks()`** - Returns a list of all registered task names

## Usage Example

```go
// Create a daily scheduled task
task := SchedTask{
    PK:          123,
    Type:        "rmm",
    Name:        "TacticalRMM_DailyCheck",
    Trigger:     "daily",
    Enabled:     true,
    DayInterval: 1,
    StartHour:   9,
    StartMinute: 30,
}

// Create the task
success, err := agent.CreateSchedTask(task)
if err != nil {
    log.Fatal(err)
}

// List all tasks
tasks := ListSchedTasks()
fmt.Printf("Found %d tasks\n", len(tasks))

// Cleanup during uninstall
CleanupSchedTasks()
```

The implementation supports various trigger types (runonce, daily, weekly, monthly, manual) and task types (rmm, schedreboot, custom), providing flexible scheduling capabilities for remote management operations.
