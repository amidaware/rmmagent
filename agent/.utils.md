Utility functions for the Tactical RMM agent providing network operations, system information gathering, file operations, and various helper functions for agent functionality.

## Key Components

### Network Operations
- **DoPing()** - Performs ICMP ping tests with detailed statistics
- **PublicIP()** - Retrieves agent's public IP address from multiple sources
- **TestTCP()** - Tests TCP connectivity to a given address
- **IsValidIP()** - Validates IPv4/IPv6 addresses

### System Information
- **TotalRAM()** - Returns system RAM in GB
- **BootTime()** - Gets system boot time as Unix timestamp
- **ShowVersionInfo()** - Displays agent version and build information

### File Operations
- **Unzip()** - Extracts ZIP archives with ZipSlip protection
- **ExtractTarGz()** - Extracts tar.gz archives
- **ByteCountSI()** - Formats byte counts in human-readable format

### Process Management
- **KillProc()** - Terminates processes and their children
- **getPowershellExe()**, **getCMDExe()** - Locates shell executables

### Helper Functions
- **GenerateAgentID()** - Creates unique 40-character agent identifiers
- **StripAll()** - Removes whitespace and newlines
- **CleanString()** - Sanitizes strings by removing invalid UTF-8 sequences
- **DjangoStringResp()** - Cleans Django API responses

## Usage Example

```go
// Ping a host
response, err := DoPing("google.com")
if err == nil {
    fmt.Printf("Ping status: %s\n", response.Status)
    fmt.Printf("Output: %s\n", response.Output)
}

// Get public IP
agent := &Agent{}
publicIP := agent.PublicIP()
fmt.Printf("Public IP: %s\n", publicIP)

// Extract archive
extractedDir, err := agent.ExtractTarGz("archive.tar.gz", "/tmp")
if err == nil {
    fmt.Printf("Extracted to: %s\n", extractedDir)
}

// Generate agent ID
agentID := GenerateAgentID()
fmt.Printf("New agent ID: %s\n", agentID)
```
