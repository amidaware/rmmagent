This is the core agent module for the Tactical RMM agent, providing the main Agent struct and command execution capabilities for remote management and monitoring across Windows, macOS, and Linux platforms.

## Key Components

### Agent Struct
- **Agent**: Main agent struct containing configuration, authentication, platform-specific paths, and service management
- **CmdStatus**: Command execution result wrapper containing status, stdout, and stderr
- **CmdOptions**: Configuration options for command execution including shell, timeouts, and environment variables

### Core Functions
- **New()**: Agent constructor that initializes platform-specific configurations, HTTP client, NATS connections, and OpenFrame integration
- **NewCMDOpts()**: Creates default command execution options
- **CmdV2()**: Advanced command execution with streaming output, timeout handling, and process management

### Platform Constants
- Cross-platform file paths and service names for Windows, macOS, and Linux
- Default directories for agent binaries, Python environments, and mesh services
- Service configuration templates

## Usage Example

```go
// Initialize a new agent
logger := logrus.New()
agent := New(logger, "1.0.0", "secret-key", "/path/to/token")

// Execute a command with custom options
cmdOpts := agent.NewCMDOpts()
cmdOpts.Command = "ls -la"
cmdOpts.Timeout = 30 * time.Second
cmdOpts.EnvVars = []string{"PATH=/usr/local/bin"}

result := agent.CmdV2(cmdOpts)
if result.Status.Exit == 0 {
    fmt.Println("Command output:", result.Stdout)
} else {
    fmt.Println("Command failed:", result.Stderr)
}

// Access agent configuration
fmt.Printf("Agent running on %s (%s)", agent.Platform, agent.GoArch)
fmt.Printf("Base URL: %s", agent.BaseURL)
```
