Platform-specific software inventory implementation for 32-bit Windows systems in the Tactical RMM agent. This file provides functionality to retrieve installed software information from the Windows registry on 386 architecture systems.

## Key Components

- **`installedSoftwareList()`** - Retrieves software list from Windows registry's 32-bit uninstall key
- **`GetInstalledSoftware()`** - Agent method that processes and formats installed software data into standardized structs

## Usage Example

```go
// Get installed software on 32-bit Windows system
agent := &Agent{}
softwareList := agent.GetInstalledSoftware()

for _, software := range softwareList {
    fmt.Printf("Software: %s v%s\n", software.Name, software.Version)
    fmt.Printf("Publisher: %s\n", software.Publisher)
    fmt.Printf("Install Date: %s\n", software.InstallDate)
    fmt.Printf("Size: %s\n", software.Size)
}
```

The function queries the Windows registry at `SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall` specifically for 32-bit applications, processes the raw data through helper functions like `CleanString()` and `ByteCountSI()`, and returns a standardized list of `trmm.WinSoftwareList` structs containing software details including name, version, publisher, install date, size, source location, and uninstall information.
