Unix-specific agent implementation providing platform functionality for non-Windows systems including disk management, system monitoring, script execution, and agent lifecycle operations.

## Key Components

**System Information Functions:**
- `GetDisks()` - Retrieves disk usage information excluding loop and dev filesystems
- `SystemRebootRequired()` - Checks if system reboot is required (Debian/RHEL)
- `LoggedOnUser()` - Returns the first logged-in user
- `osString()` - Formats OS information string with platform details

**Configuration Management:**
- `NewAgentConfig()` - Loads agent configuration from JSON files in `/etc/` or current directory
- Support for OpenFrame mode and custom mesh directories

**Script Execution:**
- `RunScript()` - Executes scripts with support for nushell, deno, and standard shells
- Handles environment variables and custom permissions
- Creates temporary files with proper permissions (0770)

**Agent Management:**
- `AgentUpdate()` - Downloads and installs agent updates with service restart
- `AgentUninstall()` - Uninstalls agent using provided script
- SELinux context restoration support

**Mesh Integration:**
- `NixMeshNodeID()` - Retrieves mesh node ID from mesh system executable
- `RecoverMesh()` - Restarts mesh service for recovery
- `GetWMIInfo()` - Collects system information including IPs, disks, CPUs, GPUs

## Usage Example

```go
agent := &Agent{}

// Get system disk information
disks := agent.GetDisks()
for _, disk := range disks {
    fmt.Printf("Device: %s, Used: %s, Free: %s\n", 
        disk.Device, disk.Used, disk.Free)
}

// Check if reboot required
rebootNeeded, err := agent.SystemRebootRequired()
if err == nil && rebootNeeded {
    fmt.Println("System reboot required")
}

// Execute a shell script
stdout, stderr, exitcode, err := agent.RunScript(
    "echo 'Hello World'", 
    "bash", 
    []string{}, 
    30, // timeout seconds
    false, // runasuser
    []string{}, // envVars
    false, // nushellEnableConfig
    "", // denoDefaultPermissions
)
```
