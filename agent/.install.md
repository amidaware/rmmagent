This file implements the installation functionality for the Tactical RMM agent, handling cross-platform deployment and configuration of remote monitoring agents.

## Key Components

**Installer Struct**: Configuration container holding installation parameters including RMM server details, authentication tokens, proxy settings, mesh agent configuration, and OpenFrame integration parameters.

**Install Method**: Main installation orchestrator that performs agent registration, mesh agent deployment, service installation, and system configuration across Windows, macOS, and Linux platforms.

**copyFile Function**: Utility function for copying files during installation process.

**Key Features**:
- Multi-platform support (Windows, macOS, Linux)
- Mesh agent integration for remote access
- OpenFrame authentication mode
- Proxy and TLS configuration
- Service/daemon installation
- System hardening options (Windows updates, RDP, ping)

## Usage Example

```go
// Create installer configuration
installer := &Installer{
    RMM:              "https://rmm.example.com",
    Token:           "installation-token",
    ClientID:        1,
    SiteID:          1,
    Description:     "Production Server",
    AgentType:       "server",
    Power:           true,
    RDP:             true,
    Ping:            true,
    Timeout:         time.Duration(30),
    OpenframeMode:   false,
    Insecure:        false,
}

// Install agent
agent := New(logger, version, "", "")
agent.Install(installer)
```

The installation process handles authentication, downloads required components, configures the agent, registers with the RMM dashboard, and sets up platform-specific services for continuous monitoring.
