This file provides Windows-specific system call wrappers for the Tactical RMM agent, enabling access to Windows Event Log operations and environment block management through direct API calls.

## Key Components

### System DLL References
- **modadvapi32**: Advanced Windows API functions (event log operations)
- **modkernel32**: Core Windows kernel functions (message formatting, library loading)
- **userenv**: User environment functions (environment block management)

### Data Structures
- **EVENTLOGRECORD**: Represents a Windows Event Log record with metadata like timestamps, event ID, and string offsets
- **ReadFlag**: Enumeration for event log reading modes (sequential, seek, forward/backward)

### Core Functions
- **FormatMessage()**: Formats Windows system messages using message resources
- **GetOldestEventLogRecord()**: Retrieves the oldest record number from an event log
- **LoadLibraryEx()**: Loads Windows DLLs with specific flags
- **ReadEventLog()**: Reads event log entries with various filtering options
- **CreateEnvironmentBlock()**: Creates environment variable block for a user token
- **DestroyEnvironmentBlock()**: Releases environment block memory
- **EnvironmentBlockToSlice()**: Converts Windows environment block to Go string slice

## Usage Example

```go
// Read event log records
var buffer [4096]byte
var bytesRead, minBytes uint32
err := ReadEventLog(
    eventHandle,
    EVENTLOG_SEQUENTIAL_READ|EVENTLOG_FORWARDS_READ,
    0,
    &buffer[0],
    4096,
    &bytesRead,
    &minBytes,
)

// Create environment block for process execution
envBlock, err := CreateEnvironmentBlock(userToken)
if err == nil {
    envVars := EnvironmentBlockToSlice(envBlock)
    DestroyEnvironmentBlock(envBlock)
}
```
