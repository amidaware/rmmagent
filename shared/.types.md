This file defines shared data types used throughout the Tactical RMM agent system, providing structured representations for agent communication, system monitoring, Windows services, and hardware information.

## Key Components

### Core Agent Types
- **`AgentConfig`** - Configuration settings for the RMM agent including URLs, tokens, and OpenFrame parameters
- **`AgentInfo`** - Basic system information like hostname, OS, RAM, and boot time
- **`CheckIn`** family - Base and specialized check-in message types for different system data

### Windows Management
- **`WinSvcResp`** - Response structure for Windows service control operations
- **`WUAPackage`** - Windows Update Agent package information with metadata
- **`Win32_ComputerSystem`** - WMI-based system information structure
- **`EventLogMsg`** - Windows event log entry representation

### Monitoring & Tasks
- **`Check`** - Comprehensive monitoring check configuration with scripts, thresholds, and conditions
- **`AutomatedTask`** - Task automation structure with actions and execution settings
- **`ProcessMsg`** - Running process information including PID, memory usage, and CPU

### System Data
- **`Disk`** - Physical disk information with usage statistics
- **`SoftwareList`** - Installed software inventory details

## Usage Example

```go
// Create agent configuration
config := &AgentConfig{
    BaseURL:       "https://rmm.example.com",
    AgentID:       "agent-123",
    Token:         "auth-token",
    OpenframeMode: true,
}

// Process system check-in with disk information
checkIn := &CheckInDisk{
    CheckIn: CheckIn{
        Func:    "disks",
        Agentid: "agent-123",
        Version: "2.1.0",
    },
    Disks: []Disk{
        {
            Device:  "C:",
            Fstype:  "NTFS",
            Total:   500000000000,
            Used:    250000000000,
            Free:    250000000000,
            Percent: 50.0,
        },
    },
}

// Define a monitoring check
check := &Check{
    CheckType: "diskspace",
    Threshold: 90,
    Disk:      "C:",
    Status:    "passing",
}
```
